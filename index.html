Riot Games Discord Tracker Bot

A Discord bot that tracks League of Legends and VALORANT matches using the Riot Games API. This page is provided to clearly demonstrate functionality, user flow, and API compliance.

Overview

This bot provides match-related information directly inside Discord for Riot Games titles. All data is informational and delivered either post-match or via Riot-supported spectator endpoints.

The bot does not automate gameplay, modify clients, or provide real-time competitive advantages.

League of Legends

Live Tracking
  • Active match detection using the Spectator API
  • Match start and end notifications via DM
  • Team compositions with champion picks
Statistics
  • Recent K/D ratios from match history
  • Individual performance comparisons
  • Post-match summaries

VALORANT

Current (Dev Key)
  • Post-match statistics from recent games
  • Recent K/D performance tracking
  • Manual stat lookup commands
With Production Key
  • Live match detection and notifications
  • Competitive rank and tier tracking
  • Team composition alerts

Features will be enabled only where supported by Riot APIs and policy.

User Flow

1

User links their Riot account via Discord

2

User opts in to tracking or stat queries

3

Bot retrieves match data from Riot APIs

4

Information is delivered in Discord

API Compliance

  • No gameplay automation or scripting
  • No unfair competitive advantage
  • Rate limiting and caching implemented
  • Only Riot-permitted data is displayed
